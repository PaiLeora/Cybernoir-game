# Sound Effects

Place these sound files here (you can download free sound effects from sites like Pixabay or Freesound):

- `clue-found.mp3` - When discovering new evidence
- `case-solved.mp3` - When solving a case
- `new-email.mp3` - Email notification
- `achievement.mp3` - Achievement unlocked
- `click.mp3` - Button click
- `notification.mp3` - General notification

If no sounds are available, the game will work without them.
