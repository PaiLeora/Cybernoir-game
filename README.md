## ✨ Features

- 🔐 **Authentication System** - Secure login with Firebase Auth
- 📊 **Player Progression** - Level up by solving cases
- 🎯 **20 Unique Cases** - Easy to Expert difficulty levels
- 🔍 **Investigation Tools**:
  - Evidence Board with drag & drop
  - Search Engine Simulator
  - Social Media Simulator
  - Email Investigation System
  - Chat Analysis
  - File Metadata Analysis
  - Timeline Builder
  - Suspect Profiling
- 🏆 **Achievements & Rewards**
- 💾 **Auto-save Progress**
- 🌙 **Cyber Noir Theme**
- 📱 **Fully Responsive**
- 🔊 **Sound Effects**

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, TailwindCSS
- **State Management**: Zustand, Context API
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth
- **Animation**: Framer Motion
- **Drag & Drop**: React DnD
- **Audio**: Howler.js
